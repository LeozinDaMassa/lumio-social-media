# Lumio

A simple, beautiful social media app where people can share ideas, photos, and videos.

![Lumio Banner](./assets/banner.png)

## About

Lumio lets users post content, like, comment, share, and follow each other — all wrapped in a clean, infinite-scrolling feed.

This project was built as a learning journey into backend development with Python, while exploring modern tools like Supabase and FastAPI.

## Tech Stack

**Backend**

- Python
- FastAPI
- Supabase (PostgreSQL + Auth + Storage)

**Frontend**

- React
- Vite
- Tailwind CSS

**Deployment**

- Vercel (frontend)
- Render (backend)

## Features

- User authentication (register/login)
- Create posts with text, images, or videos
- Like and comment on posts
- Follow and unfollow users
- Infinite scrolling feed
- User profiles
